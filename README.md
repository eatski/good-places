# いまここハザード

今いる場所の洪水・土砂災害・津波・高潮のリスクを、地図とひとことで確認できるWebページです。日本全国で使えます。

**ページ:** https://eatski.github.io/good-places/

## できること

- 現在地を地図に表示し、移動に合わせて追いかける
- 現在地の「洪水の浸水の深さ」「土砂災害警戒区域かどうか」「津波」「高潮」をまとめて表示
- 地図を押した場所や、住所・地名で検索した場所も同じように調べられる
- 地図に重ねる情報(洪水・土砂災害・津波・高潮)を切り替えられる

## データ

- 地図: [国土地理院 地理院タイル(淡色地図)](https://maps.gsi.go.jp/development/ichiran.html)
- ハザード: [ハザードマップポータルサイト](https://disaportal.gsi.go.jp/)のオープンデータ(洪水浸水想定区域 想定最大規模、土砂災害警戒区域、津波浸水想定、高潮浸水想定区域)
- 住所検索・地名: 国土地理院 地名検索API / 逆ジオコーダ

## 注意

- 浸水は想定最大規模(1000年に1度程度の大雨など)の想定です。下水があふれる内水は含みません。
- データが整備されていない地域では「想定なし」と表示されることがあります。最終的な確認は、各自治体のハザードマップで行ってください。
- 位置情報は、国土地理院から地図・ハザード・地名のデータを取ってくるためだけに使います。保存や、ほかへの送信はしません。
